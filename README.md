# 🎮 TeamGame (チームゲーム)

2人対戦・協力プレイ・ソロAI対戦に対応した、2Dトップダウン・タクティカルシューティングアクションゲーム！  
C++ および DxLib で開発されており、**1台のPCでの画面分割PvP対戦** や **AIデスマッチ**、さらに **LAN通信による対戦** に対応しています。

---

## ⚡ クイックスタート（審査・プレイ方法）

**外部サーバーの起動や特別な環境設定は一切不要です。**  
`TeamGame.exe` をダブルクリックするだけで即座に起動し、すぐにプレイできます。

### おすすめのモード選択
タイトル画面で **`START`** を選択後、以下のモードから選択できます：

1. **`1. Solo Brawl (ソロ・AIデスマッチ)`** 【1人での審査・プレイに最適】
   * 敵Bot（AI）とリアルタイムに撃ち合い、目標キル数を競うモードです。
   * 索敵AI、暗闇の視界制限、銃声の感知、草むらのステルス判定を体感いただけます。
2. **`2. Local PvP (画面分割 1P vs 2P対戦)`** 【1台のPCで3vs3チーム対戦】
   * 1台のPCで画面を左右に分割し、両チームとも「プレイヤー1人 ＋ AIボット2体」を率いて戦う本格3vs3タクティカル対戦モードです。
   * **青チーム（1P ＋ 味方Bot 2体） vs 赤チーム（2P ＋ 敵Bot 2体）**
   * **ゲームパッドを接続しての対戦はもちろん、キーボード1台だけでも2人対戦が可能です！**
   * 10キル先取したチームの勝利となります。
3. **`3. Local Co-op (画面分割 協力プレイ)`**
   * 2人で協力して敵Bot部隊と戦うモードです。
4. **`4. LAN Play (通信対戦)`**
   * ネットワークを介したオンライン・LAN対戦モードです（詳細は後述）。

## 🛠️ 技術スタック ＆ 実装のポイント

* **開発言語**: C++ (Visual Studio 2022 / C++17)
* **グラフィックス / 音響**: DxLib (DirectX)
* **画面分割・マルチカメラシステム**:
  * 1画面内でビューポート（`SetDrawArea`）を分割し、各プレイヤーに独立したカメラ追従・ズーム処理・視界マスク（視野角・暗闇演出）をリアルタイム描画。
* **索敵・ステルスAIシステム**:
  * レイキャストによる遮蔽物判定、視界コーン、銃声察知、暗闇時のステルス値変化、草むら隠蔽判定。
* **マルチ入力ハイブリッド制御**:
  * DirectInputによるゲームパッド入力とRawキーボード入力を並行処理し、同一PC上での競合を完全防止。
* **ネットワーク通信（発展的実装）**:
  * Windows標準 `WinHTTP WebSocket API` (`winhttp.lib`) を採用。
  * 外部DLLやBoost等に依存せず、マルチスレッド並行送受信（`std::thread` + `std::mutex` + `std::queue`）により60FPS描画を一切阻害しない設計。

## 🌐 オンライン通信対戦について（参考）

本作品は外部ネットワーク対戦機能も実装しています。

### 同一PC内での通信テスト（ループバック通信）
外部サーバーや外部ネットワークを使わずに、1台のPC上で通信対戦を検証できます：
1. 付属の `run_relay_server.bat` を起動してローカル中継サーバー（`localhost:8080`）を立ち上げます。
2. `server_config.ini` の `Host` を `localhost`、`Port` を `8080`、`UseSSL` を `0` に設定します。
3. ゲームを2つ起動し、片方で「部屋作成」、もう片方で「部屋参加」を行うことで通信対戦が動作します。
