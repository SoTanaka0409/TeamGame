# 🎮 TeamGame (チームゲーム)

2人対戦・協力プレイ対応の2Dトップダウン・タクティカルシューティングアクションゲーム！  
C++ および DxLib で開発されており、**Web経由（WebSocket）によるオンライン対戦** に対応しています。

---

## 🚀 クラウド中継サーバー（1クリック起動）

学校や会社のLAN制限（端末間通信の遮断）を回避し、**世界中どこからでも4桁の部屋番号で対戦**できるようにするため、無料のクラウドサーバーへ1クリックでデプロイできます。

以下のボタンをクリックすると、**Render.com** で自動的に中継サーバーが立ち上がります（完全無料）：

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/SoTanaka0409/TeamGame)

> 💡 **RenderのURLが発行されたら**:  
> 発行されたURL（例: `https://teamgame-relay-xxxx.onrender.com`）をブラウザで開くと、**サーバーの稼働状態・対戦部屋数・参加案内**が表示されます！

## 🌐 オンライン対戦への参加方法

面倒なIPアドレスの入力は一切不要です！

```
【ホスト】部屋を作成 ──(4桁コードを伝える: 例 3842)──> 【ゲスト】コードを入力 ──> 即対戦開始！
```

### ステップ1：設定ファイル（server_config.ini）の準備
ゲームフォルダ内の `server_config.ini` をメモ帳で開き、サーバーのURLを設定します：

```ini
[Server]
Host=teamgame-relay-xxxx.onrender.com   ; サーバーのホスト名 (Render等のURL)
Port=443                               ; ポート番号 (HTTPSは443)
UseSSL=1                               ; 暗号化通信 (クラウドは1)
```

※ローカルPC（1台でテスト）の場合は、付属の `run_relay_server.bat` を起動して以下のように設定します：
```ini
[Server]
Host=localhost
Port=8080
UseSSL=0
```

### ステップ2：ゲームを起動してマッチング
1. ゲーム（`TeamGame.exe`）を起動します。
2. タイトルメニューで **`Web Online (インターネット対戦)`** を選択します。
3. **ホスト側（1人目）**:
   * **`Create Room (部屋を作成・ホスト)`** を選びます。
   * 画面に大きく **`部屋番号: 3842`** のように4桁の番号が表示されます。
   * **`C` キー** を押すと部屋番号がクリップボードにコピーされます。
4. **ゲスト側（2人目）**:
   * **`Join Room (部屋番号で参加)`** を選びます。
   * 教えてもらった4桁の部屋番号を入力して Enter！
5. **一瞬でお互いの画面がゲーム本編へ進み、リアルタイム対戦がスタートします！**

## ⌨️ 操作方法

| アクション | キーボード / マウス | ゲームパッド |

## 🛠️ 技術スタック & 特徴

* **開発言語**: C++ (Visual Studio 2022 / C++17)
* **グラフィックス / 音響**: DxLib (DirectX)
* **オンライン通信**: Windows標準 `WinHTTP WebSocket API` (`winhttp.lib`)
  * 外部ライブラリ（Boostや外部DLL）を一切使用せず、Windows標準APIのみでWebSocketクライアントを実装
  * 60FPSの描画を一切ブロックしないマルチスレッド並行受信（`std::thread` + `std::mutex` + `std::queue`）
* **中継サーバー**: Python (`websockets`) / HTML Webダッシュボード内蔵
* **対応モード**:
  * 1P (ソロプレイ)
  * 2P (同一PC・画面分割ローカル協力)
  * Web Online (4桁コードによるインターネット対戦)
  * LAN Play (ローカルLAN直接対戦)
