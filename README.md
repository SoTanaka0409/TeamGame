# 🎮 Blind Zone (ブラインド・ゾーン)

視界と音を駆使して戦う、2Dトップダウン・タクティカルステルスシューティングアクション！  
C++ および DxLib で開発されており、リアルタイムな索敵AI、暗闇の視界制限（ライト・視野角マスク）、銃声の感知、草むらのステルス判定を備えた**本格シングルプレイ・タクティカルバトル**が楽しめます。

---

## ⚡ クイックスタート（プレイ方法）

**外部サーバーや複雑な設定は一切不要です。**  
`TeamGame.exe` をダブルクリックするだけで即座に起動し、すぐにプレイできます。

1. タイトル画面で **`GAME START`** を選択
2. 使用するキャラクターを選択（各キャラクターごとに異なる戦術スキルを保有）
3. 使用する武器を選択（ハンドガン、ショットガン、スナイパーライフル等）
4. ゲーム開始！味方Botと共に敵部隊を撃破し、目標キル数を達成してください。

---

## ⌨️ 操作方法（キーボード ＆ マウス / ゲームパッド）

| アクション | キーボード ＆ マウス | ゲームパッド |
| :--- | :--- | :--- |
| **移動** | `W` `A` `S` `D` | 左スティック / 十字キー |
| **照準（エイム）** | マウスカーソル移動 | 右スティック |
| **射撃** | マウス左クリック / `Z` キー | A ボタン / RT トリガー |
| **懐中電灯 ON/OFF** | マウス右クリック | Y ボタン / X ボタン |
| **リロード** | `R` キー | L1 ボタン |
| **武器切り替え** | `Q` キー / `1` `2` `3` キー / マウスホイール | LB ボタン |
| **ナイフ暗殺** | `Space` キー（背後ステルス時） | B ボタン |
| **スキル発動** | `F` キー | RT ボタン |
| **エイムロック（視点固定）** | `E` キー | - |
| **ポーズ / メニュー** | `Esc` キー | START ボタン |

---

## 🛠️ 技術スタック ＆ 実装のポイント

* **開発言語**: C++ (Visual Studio 2022 / C++17)
* **グラフィックス / 音響**: DxLib (DirectX)
* **索敵・ステルスAIシステム**:
  * レイキャストによる遮蔽物判定、視界コーン、銃声察知、暗闇時のステルス値変化、草むら隠蔽判定。
* **カメラ ＆ 視界演出システム**:
  * 武器の射程に応じた動的エイムカメラオフセット、プレイヤーの懐中電灯照射コーンおよび全方位ライトマスク、薄明時間帯（月光）イベント。
* **ゲームバランス ＆ 演出**:
  * ペルソナ風スタイリッシュカットイン演出、デンジャー血しぶきオーバーレイ、ソナー探知リングエフェクト。
