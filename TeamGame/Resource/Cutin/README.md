# カットイン画像配置フォルダ (Cutin Image Directory)

キャラクターごとのスキル発動時カットイン画像をこのフォルダに配置してください。
画像が存在する場合は自動的にカットインのスリット枠に反映されます。
（画像が存在しない場合は自動でP5風の劇画イラストが描画されます）

## ファイル名の命名規則
- `cutin_1.png` : 1番「指揮者」用カットイン画像
- `cutin_2.png` : 2番「反逆者」用カットイン画像
- `cutin_3.png` : 3番「バカ」用カットイン画像
- `cutin_4.png` : 4番「主婦」用カットイン画像
- `cutin_5.png` : 5番「悪魔」用カットイン画像

## おすすめの画像仕様
- **切り抜き範囲**: キャラクターの「両目＋眉間＋鼻筋」のクローズアップ
- **画像比率**: 横長（およそ 3:1 〜 4:1、例: 800x200px または 1200x300px）
- **画像形式**: PNG (背景透過 または 黒背景推奨)
