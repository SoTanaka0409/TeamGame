① モデルのスケール設定（最重要）

Blenderから出力したモデルはcm単位（標準の100倍）で作られているため、DxLibでは 0.01倍 に縮小する必要があります。

cpp
// 読み込み直後に0.01倍に縮小（等身大になります）
MV1SetScale(modelHandle, VGet(0.01f, 0.01f, 0.01f));

※これを設定しないと、画面いっぱいに超巨大な巨人として表示されてしまいます。

② アニメーションの番号（インデックス）

通常版モデル（青・緑・赤など）には、以下の番号でアニメーションが収録されています。

[0] : 待機モーション（Idle）
[1] : 歩行モーション（Walk）
[2] : やられ / 死亡モーション（Die）

相手がアニメーションを番号でアタッチしている場合は、以下のように指定すれば動きます：

cpp
// 待機アニメーションを再生する場合
int attachIndex = MV1AttachAnim(modelHandle, 0, -1, FALSE);
// 歩行アニメーションを再生する場合
int attachIndex = MV1AttachAnim(modelHandle, 1, -1, FALSE);
③ モデルの向き（初期回転）

モデルの正面は手前を向いて作成されているため、ゲームのカメラに合わせて必要であれば初期角度（180度など）を調整してもらってください。

cpp
// 奥を正面にして歩かせたい場合（Y軸を180度回転）
MV1SetRotationXYZ(modelHandle, VGet(0.0f, DX_PI_F, 0.0f));
