========================================================================
 TeamGame 開発ガイドライン & 命名規則メモ (DEVELOPMENT_NOTE.txt)
========================================================================

■ 概要
このメモは、プロジェクト「TeamGame」を別のパソコンや他のチームメンバー、
ならびに Antigravity などの AI アシスタントで作業する際の共通ルールを記録したものです。

------------------------------------------------------------------------
1. ファイル文字コード & 改行コード
------------------------------------------------------------------------
- 文字コード: UTF-8 with BOM (utf-8-sig)
  ※ MSVC (Visual Studio) で日本語コメントを含むファイルをビルドする際、
    BOM がないと文字化けやコンパイルエラー (C4828等) が発生するのを防止するためです。
- 改行コード: CRLF (\r\n)

------------------------------------------------------------------------
2. 命名規則
------------------------------------------------------------------------
- クラス名: PascalCase (例: Player, GameScene, ColliderManager)
- 関数/メソッド名: PascalCase (例: SpawnEnemiesRandomly, Update, Draw)
- メンバ変数名: camelCase (例: team0Kills, maxKills, playerWorldX)
- ディレクトリ構成:
  - TeamGame/Source/Core
  - TeamGame/Source/Characters
  - TeamGame/Source/Weapons
  - TeamGame/Source/Managers
  - TeamGame/Source/Scenes
  - TeamGame/Source/Colliders
  - TeamGame/Source/Stage
  - TeamGame/Source/Objects

------------------------------------------------------------------------
3. チームIDとキル数表示ルール
------------------------------------------------------------------------
- teamId = 0 : プレイヤーおよび味方 Bot
  - 撃破スコア (team0Kills): ENEMY KILLS (青バー表示) -> 敵を倒すと増加
- teamId = 1 : 敵 Bot
  - 撃破スコア (team1Kills): ALLY LOSSES (赤バー表示) -> 味方が倒されると増加

------------------------------------------------------------------------
4. Doxygen形式のコメントルール
------------------------------------------------------------------------
関数やクラスには以下の標準Doxygen形式で日本語コメントを付与します。
/**
 * @brief [概要]
 * @param [引数名] [引数の説明]
 * @return [戻り値]
 * @details [詳細な処理]
 */

------------------------------------------------------------------------
5. ビルドおよびコミット時の注意事項
------------------------------------------------------------------------
- ビルド環境: Visual Studio 2022 (x86 / Debug)
- 編集後は必ず MSBuild 等で 0 エラーであることを確認してください。
- AIツール (Antigravity等) は、このファイルおよび GEMINI.md を自動参照して作業を継続します。

------------------------------------------------------------------------
6. AI アシスタント運用ルール (Antigravity 等)
------------------------------------------------------------------------
① コミット・Push の自律実行禁止:
  - AI は普段の作業において、自律的に git commit や git push を行ってはならない。
  - ユーザーから「コミットPUSHまでして」等の明示的な指示があった場合のみ実行する。
② 変更点まとめ・報告フォーマット:
  - Antigravity での作業完了・区切り時には、AI による変更点および手作業修正を含めて日本語で報告する。
  - コミット用要約: 最大でも2行（簡潔なタイトル・概要のみ。例: 「プレイヤー専用HUD（HP/MPバー）の画面左下実装。」「ゲーム中ESCポーズキー不具合の修正。」）。
  - 補助資料: 2行に収まらない詳細内容・補足説明・変更仕様などは「補助資料」として別枠に切り分けて記載する。
